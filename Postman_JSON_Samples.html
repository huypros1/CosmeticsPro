💄 HQCosmetic - Mẫu JSON Gửi API

Tài liệu tổng hợp các mẫu JSON payload để bạn copy nhanh vào Body (raw -> JSON) trên Postman.

POST /api/auth/register

Đăng ký tài khoản

Đăng ký thành viên mới.

{
  "name": "Nguyễn Văn A",
  "email": "nguyenvana@gmail.com",
  "password": "password123",
  "password_confirmation": "password123"
}

POST /api/auth/login

Đăng nhập 
{
  "email": "admin@hqcosmetic.vn",
  "password": "password"
}

POST /api/profile/addresses

Thêm địa chỉ giao hàng

Header: Authorization: Bearer {token}

{
  "address_line": "123 Đường Lê Lợi, Phường Bến Thành, Quận 1, TP.HCM",
  "phone": "0901234567",
  "is_default": true
}

POST /api/cart

Thêm vào giỏ hàng

Header: Authorization: Bearer {token}

{
  "variant_id": 1,
  "quantity": 2
}

PUT /api/cart/{cart_id}

Cập nhật số lượng giỏ hàng 
{
  "quantity": 5
}

POST /api/orders

Tạo đơn hàng (Checkout)

Header: Authorization: Bearer {token}. Thay shipping_address_id bằng id hợp lệ của user.

{
  "shipping_address_id": 1,
  "voucher_id": null,
  "payment_method": "cod",
  "shipping_fee": 30000,
  "total_amount": 425000,
  "items": [
    {
      "variant_id": 1,
      "quantity": 1,
      "price": 395000
    }
  ]
}

POST /api/products/{id}/reviews

Đánh giá sản phẩm

Header: Authorization: Bearer {token}

{
  "rating": 5,
  "comment": "Sản phẩm xài rất mướt, giao hàng nhanh, đóng gói cẩn thận. Rất ưng ý!"
}

POST /api/vouchers/validate

Kiểm tra Voucher 
{
  "code": "WELCOME10",
  "order_value": 500000
}

Chỉ cần bôi đen -> Copy, hoặc nhấn nút Copy để đưa vào tab Body -> raw -> JSON trong Postman.
